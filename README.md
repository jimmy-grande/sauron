# sauron

Minimalist observability library written in TypeScript.

## Install

```sh
pnpm install sauron
```

## Development

This repository uses [pnpm](https://pnpm.io) and requires Node.js 22 or newer.

```sh
pnpm install
pnpm lint
pnpm test
pnpm build
```

Create a changeset when your change affects the public API:

```sh
pnpm changeset
```
